## Open questions (from the plan) — resolutions used here

- **(item 6) Slug TTL:** default 7 days, configurable via `SHARE_TTL_DAYS`. Kept simple — no per-share override.
- **(item 7) Migration:** the existing global prompt-settings row is preserved and backfilled to `repo_id=NULL` (the global default), not wiped.
- **(item 8) CLI↔API auth:** static bearer token in `STANDUP_API_TOKEN` (env), matching the plan's named variable. No JWT/OAuth — the project has no other auth surface and runs behind Tailscale.
- **(item 11) `slowapi` vs hand-rolled:** resolved in Foundation — hand-rolled, no new dep.
